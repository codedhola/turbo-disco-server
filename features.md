## ✨ Features

- **Go-based server**  
  Lightweight and fast server built with Go.

- **WebSocket support**  
  Real-time, bi-directional communication between clients and server.

- **Real-time chat**  
  Send and receive messages instantly.

- **Chat rooms**  
  Support for public and private rooms.

- **User connection management**  
  Track connected users and active sessions.

- **Basic authentication**  
  Simple user authentication flow.

- **Roles & permissions**  
  Role-based access control (admin, moderator, user).

- **Rate limiting**  
  Protect the server from spam and abuse.

- **Message validation**  
  Ensure messages meet required format and size rules.

- **Message broadcasting**  
  Efficient message delivery to room participants.

- **Join & leave notifications**  
  Notify users when someone enters or exits a room.

- **Online users tracking**  
  Keep track of currently connected users.

- **In-memory storage**  
  Simple in-memory state for users, rooms, and messages.

- **Sound trigger events**  
  Emit events for message, join, and leave sounds on the client side.

- **Basic logging**  
  Server-side logging for connections and events.

- **Graceful shutdown**  
  Cleanly close connections on server stop.

- **Environment-based configuration**  
  Configure ports, limits, and settings using environment variables.
